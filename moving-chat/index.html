후원 시그·캐릭터 공용 설치파일 받기
처음 사용하거나 이전 버전을 쓰고 있다면 압축을 모두 풀고 Install.cmd를 실행하세요. 내 문서의 ‘남하루 설치파일’에 설치되며 기존 설정은 유지됩니다.
OBS에서 브라우저 소스 추가 → 로컬 파일 체크 → 찾아보기 → 문서(내 문서) → 남하루 설치파일 → NAMHARU-Characters-OBS.html 선택 → 열기. 권장 너비 1920 / 높이 1080.
한 번 등록하면 설정·전용 이미지가 자동 반영됩니다. 설치된 파일의 위치나 이름을 바꾸면 자동 반영되지 않습니다. 설정 페이지는 방송 중 닫아도 됩니다.
