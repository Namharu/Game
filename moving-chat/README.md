# 움직이는 채팅 (개발중)

팬더 스킨 메인의 캐릭터 편집기입니다. **현재 팬더 실시간 채팅 연결은 제공하지 않습니다.**

## 제공 기능
- 투명 배경 기본 캐릭터 4종, 다중 선택, 이동·점프, 닉네임별 말풍선
- 사용자 PNG/GIF/WebP 등록, 기본/멈춤/기쁨/슬픔/화남 이미지, 좌우 반전, 수정·삭제
- 사용자 이미지는 브라우저 IndexedDB에만 저장. 서버 업로드 없음. 한 장 4MB/4096px 이하, 사용자 캐릭터 20종/64MB까지
- 말풍선 6종, 5가지 색상, 글꼴·크기·표시시간·닉네임 표시 설정
- 테스트 명령: `!공지 내용`, `!타이머 5:00`, `!시간`, `!방송시간` (끄기/중지 지원)
- 명령은 로컬 테스트의 broadcaster/manager 역할만 허용. 이 역할 선택은 실제 인증이 아님.
- 향후 실채팅 어댑터는 반드시 팬더 서버의 신뢰할 수 있는 역할 필드를 검증해야 함. 닉네임이나 사용자가 보낸 역할 문자열을 신뢰하면 안 됨.
- OBS WebSocket 5 연결: 로컬 포트, 인증 지원, GetStreamStatus만 요청. 송출 시작/중지 명령 없음. 비밀번호 저장·내보내기 없음.
- OBS 미연결 시 방송시간을 만들지 않음. 방송 대기/연결 끊김/재연결 상태 구분.
- OBS 미리보기 HTML 내보내기: 선택 이미지 및 글꼴 포함, 투명 배경, 가상 채팅. HTML에는 실채팅 연결이나 OBS 비밀번호가 포함되지 않음.

## 확인
`node moving-chat/engine.test.cjs`

명령 역할 차단, 타이머 경계, OBS 경과 시간/오프라인 상태, 모의 OBS 인증 프로토콜 및 읽기 전용 요청 검사.
브라우저에서 캐릭터 등록·수정·삭제·새로고침 후 유지, 스킨 6종 전환, HTML 다운로드 및 실행, 390px 모바일 화면 확인.
실제 OBS 송출 중 시간 읽기와 실제 팬더 채팅 수신은 검증하지 않았습니다.
