# 움직이는 채팅 (개발중)

팬더 스킨 메인의 캐릭터 편집기입니다. 개인 팬더 채팅 위젯 주소로 실제 채팅을 수신하는 시험 기능을 제공합니다.

## 제공 기능
- 투명 배경 기본 캐릭터 4종, 다중 선택, 이동·점프, 닉네임별 말풍선
- 사용자 PNG/GIF/WebP 등록, 기본/멈춤/기쁨/슬픔/화남 이미지, 좌우 반전, 수정·삭제
- 사용자 이미지는 브라우저 IndexedDB에만 저장. 서버 업로드 없음. 한 장 4MB/4096px 이하, 사용자 캐릭터 20종/64MB까지
- 말풍선 6종, 5가지 색상, 글꼴·크기·표시시간·닉네임 표시 설정
- 공지·타이머·시각·방송시간은 채팅스킨의 위젯 메뉴로 이동했습니다.
- OBS 미리보기 HTML 내보내기: 선택 이미지 및 글꼴 포함, 투명 배경, 가상 채팅. HTML에는 개인 연결키가 포함되지 않음. OBS 상호작용에서 주소를 입력해 연결할 수 있음.

## 확인
`node chat-skins/widget-runtime.test.cjs`

명령 역할 차단, 타이머 경계, OBS 경과 시간/오프라인 상태, 모의 OBS 인증 프로토콜 및 읽기 전용 요청 검사.
브라우저에서 캐릭터 등록·수정·삭제·새로고침 후 유지, 스킨 6종 전환, HTML 다운로드 및 실행, 390px 모바일 화면 확인.
2026-11-24 사용자 제공 위젯으로 실제 채널 구독, 실제 채팅 2건 수신, 닉네임별 캐릭터·말풍선 표시를 확인했습니다. 실제 방송자 공지 명령은 chat-skins의 위젯에서 확인했습니다. OBS 송출 시간 읽기는 모의 프로토콜 검사만 완료했습니다.

## 개인 연결 정보
개인 위젯 주소는 메모리에만 보관하며 localStorage, HTML 다운로드, 소스 코드에 저장하지 않습니다.
사용자가 누르는 ‘OBS 실제 채팅 주소 복사’에는 URL fragment에 개인 주소가 포함됩니다. 해당 fragment는 GitHub Pages HTTP 요청에 전송되지 않습니다. OBS 브라우저 소스에는 개인 주소가 저장되므로 해당 URL은 공유하지 않아야 합니다.
연결 중 샘플 채팅 및 로컬 역할 테스트는 중단됩니다. 연결 오류가 나도 가상 채팅으로 자동 대체하지 않습니다.
