# 동물 서바이벌

독립 실행되는 WebGL 미니게임입니다. 외부 게임 페이지, 광고, 원격 모델 또는 CDN 요청 없이 동작합니다. Three.js 0.170.0은 `vendor/`에 포함하며 MIT 라이선스 원문을 함께 배포합니다. 동물, 경기장, 관중과 효과는 자체 절차적 메시로 구성했습니다.

## 경기장

| 맵 | 동작 |
| --- | --- |
| 노을 절벽 | 낙석 경고, 충격, 부서지는 울타리, 줄어드는 경기장 |
| 풍차 언덕 | 방향을 바꾸는 회전 막대, 넉백과 넘어짐 |
| 얼음 섬 | 낮은 마찰, 생성되는 구멍, 줄어드는 얼음 |
| 구름 다리 | 돌풍, 발판 붕괴, 가까운 발판으로 점프 |
| 달리는 버스 | 판자와 사다리로 이동, 지나가는 장애물, 도로와 배경 이동 |
| 공장 | 용광로, 반대 방향 컨베이어, 프레스, 끝부분 분쇄기 |

2~16명, 참가자 이름, 예상 경기 시간 30/60/90/120초, 효과음 음량, 일시정지, 재경기 및 최종 순위를 지원합니다. 시간 설정은 목표 진행 속도이며 정확한 종료 시각은 아닙니다. 충돌·낙하에 따라 더 일찍 종료될 수 있습니다. 설정은 브라우저에 저장됩니다. 탭이 숨겨지면 진행을 멈춥니다.

## 실행과 검증

저장소 루트를 정적 HTTP 서버로 실행하고 `/survival/` 또는 `/#survival`을 엽니다. ES 모듈을 사용하므로 `file://`로 직접 열지 않습니다.

```
node survival/tests/simulation.mjs
```

테스트는 실제 Three.js 객체와 게임 시뮬레이션을 사용하되 WebGL 렌더러·DOM·오디오를 대체합니다. 고정 난수 시드로 6개 맵 × 3개 참가 인원 × 4개 시간 설정, 총 72경기의 종료·단일 우승자·순위 중복·유한 좌표·초기화·일시정지를 확인합니다. 렌더링과 브라우저 조작은 별도로 시각 확인합니다.
