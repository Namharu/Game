02 CSS 복사해서 적용

기존 팬더 채팅 위젯의 디자인과 고정 문구만 변경합니다. !공지 명령은 위의 OBS 적용 주소 방식을 사용하세요.
우리 사이트에 방송 계정을 연결할 필요가 없습니다.

선택한 스킨과 설정이 자동 저장됩니다.

1

팬더 채팅 소스 선택

OBS에서 사용 중인 팬더 채팅 브라우저 소스를 더블클릭해 속성을 여세요. 처음이라면 팬더 방송도우미의 채팅 프리셋 주소를 브라우저 소스에 넣으세요.

2

CSS 붙여넣기

이 페이지에서 ‘팬더용 CSS 복사’를 누른 뒤 OBS 속성의 ‘사용자 지정 CSS’에 붙여 넣으세요. 기존 CSS가 있다면 먼저 따로 복사해 두세요.

3

확인하면 적용 완료

OBS에서 확인을 누르세요. 디자인을 바꾸려면 새 스킨의 CSS만 다시 붙여 넣으면 됩니다. 팬더 위젯 주소는 그대로 사용하세요.

CSS 보기 · 직접 복사

팬더 방송도우미(p.pandahp.kr)의 채팅 위젯 전용입니다. 팬더 시청 페이지나 화면 캡처에는 적용되지 않습니다. OBS 로컬 녹화와 사용자 테스트 방송에서 채팅 수신을 확인했습니다. 새 디자인은 미리보기에서 확인한 뒤 적용하세요. 되돌릴 때는 기존 CSS를 복원하세요.
