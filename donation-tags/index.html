방송 연결
처음 사용하는 분 · 최초 설치와 OBS 등록

Windows x64 설치 파일 다운로드 · 실행 환경 포함 (.zip)

  1. 위 설치 파일을 받아 압축을 모두 푼 뒤 Install.cmd를 실행하세요. 필요한 실행 환경이 모두 포함되어 있어 설치 중 추가 다운로드는 없습니다. 설치 후 테스트 후원창이 열립니다. 실제 방송 연결에는 인터넷이 필요합니다.
  2. 설치 후 왼쪽의 OBS 파일 절대경로 복사 버튼을 누르세요.
  3. OBS 소스 목록에서 ＋ → 브라우저를 추가하고 로컬 파일을 체크한 뒤, 복사한 절대경로를 붙여넣으세요. 최초 한 번만 등록하면 됩니다.
  4. 이 페이지의 미리보기에서 테스트·이동·크기를 조절하세요. 연결된 OBS에는 시그와 네임택만 표시됩니다.

옵션과 이미지를 수정하면 같은 HTML 파일에 자동 저장됩니다. 이후에는 OBS 소스만 새로고침하세요. 파일 위치와 이름을 변경하면 OBS에서 사용 중인 파일에 수정사항이 반영되지 않습니다.

설정·개인 채팅 주소·전용 이미지는 PC에 보관하며, 후원 내역은 파일에 저장하지 않습니다.

표시 조건과 배열

HTML 파일 저장을 한 번 연결하면 개수 조건·정렬·크기 변경이 같은 파일에 자동 저장됩니다. 저장 완료 후 OBS만 새로고침하세요.

아래 끝에 도달하면 오른쪽 열에 배치하고, 전체 공간이 부족하면 축소합니다. 후원은 개수 제한 없이 보존합니다.

미리보기에서 드래그하거나 클릭 후 방향키로 이동하세요. Shift+방향키: 10칸 이동 · Alt+드래그: 자동 맞춤 해제. 직접 배치는 한 장씩, 겹치기는 같은 닉네임 묶음으로 이동합니다.

아래 겹치기: 가장 큰 단일 후원 시그만 위에 표시하고 나머지는 이름·개수를 아래에 표시합니다.

특정 후원자 전용 네임택

후원자마다 하단 닉네임을 대신할 이미지를 등록하세요. 위쪽 후원 시그와 개수는 유지됩니다. PNG·움직이는 GIF 등 최대 20MB.

PC에서 선택한 개인 네임택은 아래 ‘이미지 포함 OBS 파일 저장’으로 HTML을 저장한 뒤, OBS 브라우저 소스의 ‘로컬 파일’로 사용하세요. 링크 복사만으로는 PC 이미지가 OBS에 전달되지 않습니다.

추가할 때는 ‘＋ 후원자 추가’를 누르세요. 기존 목록은 유지되며 HTML 저장 시 기존 네임택과 새 네임택이 모두 포함됩니다. 이미 등록한 사람의 이미지는 해당 칸에서 변경하세요.
자동 저장을 연결했다면 적용한 변경은 같은 HTML에 자동 저장됩니다. 연결하지 않았다면 추가·변경·삭제 후 HTML을 다시 저장하세요. OBS가 사용하는 파일을 같은 위치·이름으로 교체하고 소스를 새로고침하면 됩니다. 다운로드한 파일 이름에 (1)이 붙으면 기존 OBS 파일은 바뀌지 않습니다.
등록 목록은 현재 브라우저에 저장됩니다. 다른 브라우저·PC에서 열거나 브라우저 데이터를 삭제하면 목록이 복원되지 않으므로, 기존 목록이 보이는지 확인한 뒤 추가하세요.

OBS 파일 자동 저장

OBS에서 사용하는 HTML 파일을 선택하세요. 이후 적용한 후원자 추가·수정·삭제와 옵션 변경을 같은 파일에 자동 저장합니다.

PC Chrome·Edge 지원. 다시 열 때 쓰기 권한 확인이 필요할 수 있습니다. 저장 완료 후 OBS 소스를 새로고침하세요.

저장한 HTML을 OBS 브라우저 소스의 로컬 파일로 선택하세요. 이미지와 설정이 포함되며 GitHub에 업로드하지 않습니다. 연결 주소를 입력했다면 연결 정보도 포함되므로 파일을 공개하지 마세요.

OBS 크기 권장: 1920 × 1080. 전체 영역의 위치는 OBS에서 조절하세요.

위젯 주소는 연결 권한을 포함합니다. 복사한 OBS 주소를 공개하지 마세요.
