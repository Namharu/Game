# 후원 시그

OBS 상호작용: 설정 화면의 가상 후원 닉네임·개수를 정하고 OBS 주소를 다시 복사합니다. OBS 브라우저 소스의 상호작용 창 내부를 클릭한 뒤 T 키로 테스트 후원을 표시하고 X 키로 단축키 테스트만 삭제합니다. 조작 UI는 방송에 그리지 않습니다. 실제 후원 및 방송도우미에서 수신한 후원은 X로 지우지 않습니다. 테스트는 현재 필터를 따르며 후원 개수 때문에 기존 카드를 삭제하지 않습니다. overlay.html#demo=1 은 연결 없이 단축키를 확인하는 로컬 데모입니다.

index.html에서 개인 채팅 위젯 주소를 연결하고 OBS 주소를 복사합니다. overlay.html은 투명 배경입니다. 설정 변경 후 OBS 주소를 다시 복사해야 합니다. 설정만 로컬에 저장하며 개인 위젯 키는 저장하지 않습니다. OBS 주소의 fragment에는 연결 키가 포함되므로 공개하지 마세요.

일반 SponCoin / ItemCoin과 helper HelperAddSpon 테스트 후원을 수신합니다. 후원에 포함된 heart.image를 우선 사용하며, 없으면 /heart/secret 시그 목록에서 기본 위젯과 같은 우선순위로 고정 이미지를 찾습니다. 정확한 닉네임의 HTTPS 이미지로 교체할 수 있습니다. 이미지를 얻지 못하면 개수 카드를 표시합니다.

후원별 개수는 합산하지 않습니다. 닉네임별로 개수와 관계없이 받은 순서대로 50% 겹칩니다. 후원 수·인원 제한으로 삭제하지 않습니다. 영역이 부족하면 전체를 축소하고 기본 60%에서 옆 빈 공간에 묶음 단위로 배치합니다. 전체 공간도 부족하면 모두 보존하기 위해 추가 축소합니다. 유지 시간을 0보다 크게 직접 설정하면 그 시간에 따른 만료는 적용됩니다. 새로고침하면 표시된 후원은 초기화됩니다. 실시간 연결 전후 누락된 후원 내역을 재조회하지 않습니다.

검증: node donation-tags/core.test.cjs 및 node shared/panda-chat.test.cjs. 실제 방송 테스트는 별도 필요합니다.
