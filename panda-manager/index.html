팬더 매니저자동 인사 · 명령어 · 신청곡내장 브라우저 · 음소거
반드시 매니저용 부계정으로 로그인하세요.

프로그램은 로그인한 부계정의 닉네임으로 채팅을 보냅니다. 방송하는 본계정과 별도로 사용하세요. 매니저 권한이 필요한 기능은 방송자가 이 부계정을 매니저로 등록해야 합니다.

시작하기기능 설정명령어 예시반복 전송문제 해결

QUICK START

처음이라면, 이 순서대로.

  1. 다운로드하고 압축을 모두 풀어요.

    ZIP 안의 PandaManager 폴더를 원하는 위치에 풀고 PandaManager.exe를 실행하세요. EXE만 따로 옮기지 말고 옆의 파일과 폴더를 함께 보관하세요.

  2. 부계정으로 로그인해요.

    저장된 로그인 정보가 없으면 로그인창이 자동으로 열립니다. 매니저로 사용할 부계정의 아이디와 비밀번호를 입력하세요. ‘자동 로그인’을 체크하면 이 PC에 암호화하여 저장합니다. 다음 실행에는 저장한 계정으로 로그인합니다.

  3. 관리할 BJ를 추가해요.

    ‘BJ 추가’를 누르고 BJ 이름과 BJ 아이디를 입력하세요. 이름은 알아보기 쉬운 표시용 이름이고, 아이디에는 방송 주소 끝의 아이디만 적으면 됩니다.

  4. 기능을 고르고 설정을 저장해요.

    자동 인사·명령어·신청곡 등 필요한 기능을 켜세요. 왼쪽 제목 아래의 ‘설정 저장’은 화면을 내려도 계속 보입니다. 설정을 바꾼 뒤 꼭 저장하세요.

  5. ‘자동 관리 시작’을 눌러요.

    로그인만으로 관리를 시작하지는 않습니다. 방송이 꺼져 있으면 주기적으로 확인하고, 켜지면 입장합니다. 다음 실행부터 자동으로 관리하려면 ‘프로그램 실행 시 이 방 자동 관리’를 체크하고 저장하세요.

OBS 연결이나 크롬 확장프로그램은 필요 없습니다. 프로그램을 켜둔 PC에서 작동하며, 내장 방송 브라우저는 항상 음소거입니다.

기능은 탭에서 설정하세요.

자동 인사

입장·추천·하트 후원에 보낼 인사를 설정합니다. {닉네임}과 {하트}는 실제 이름과 후원 개수로 바뀝니다. 입장 인사는 수신된 입장 이벤트에 반응합니다.

명령어 · 내장 명령어

직접 만든 답변과 현재 시간·타이머·계산기·순위의 명령어를 관리합니다. 사용 여부, 이름, 별칭, 권한을 고르고 저장하세요.

신청곡 · 순위

신청곡을 목록에 저장하고 직접 추가·완료·삭제할 수 있습니다. 채팅순위는 프로그램이 연결되어 수신한 내역을 집계하며, 팬더 전체 과거 기록은 아닙니다.

방송 종료가 확인된 뒤 1시간이 지나면 신청곡·채팅순위를 자동 초기화합니다. 1시간 안에 리방하면 누적 순위를 유지합니다. BJ와 명령어 설정은 유지됩니다.

채팅 · 활동

받은 채팅과 처리 상태를 확인하고 직접 메시지를 보냅니다. ‘방송창 보기’를 누르면 내장 브라우저를 확인할 수 있습니다.

명령어 앞의 !는 이미 붙어 있습니다. 입력칸에 ‘타이머’를 적으면 !타이머, ‘!정지’를 적으면 !!정지가 됩니다. 권한은 ‘누구나 / 매니저·BJ / BJ만’ 중에서 선택합니다.

신청곡은 ‘신청곡 받기’를 켜야 작동합니다. 타이머 등은 설정한 권한에 맞는 계정에서 사용하세요.

반복 명령과 반복 공지.

시작·정지 명령으로 반복

‘반복 명령 추가’에서 시작·정지 명령어와 보낼 메시지를 등록합니다. 메시지를 여러 개 넣으면 순서대로 반복합니다.

간격은 0.5초 · 1초 · 2초 · 3초 중에서 선택합니다. 실제 전송은 연결·서버 응답에 따라 늦어질 수 있습니다.

예: 시작칸에 응원, 정지칸에 정지 → 채팅에서 !응원으로 시작, !정지로 중지.

여러 반복 명령에 같은 정지 명령어를 사용해도 됩니다. 방마다 하나만 실행되며 다른 반복을 시작하면 교체됩니다.

일정 간격으로 공지

‘반복 공지’에서 ‘공지 추가’를 누르고 공지마다 내용·간격·사용 여부를 설정하세요. 여러 공지를 각각 관리할 수 있습니다.

공지 간격은 최소 60초입니다. 설정 저장이나 재접속 후에는 정한 간격만큼 기다린 뒤 보냅니다.

반복 명령은 설정 저장·관리 중지·연결 끊김 때 멈춥니다. 다시 실행하려면 시작 명령을 보내세요.

자주 막히는 부분.

로그인했는데 아무 반응이 없어요.

BJ를 선택하고 ‘자동 관리 시작’을 눌렀는지 확인하세요. 방송 연결 상태와 기능 사용 여부, 명령어 권한을 확인한 뒤 설정을 저장하세요.

매니저로 로그인한 부계정 자신의 채팅에는 자동 반응하지 않습니다. 본계정 등 다른 계정으로 테스트하세요. 같은 사람의 같은 명령은 30초 동안 중복 반응을 제한합니다.

로그인 화면이나 추가 인증을 확인하고 싶어요.

왼쪽 ‘로그인 브라우저 보기’를 누르세요. 계정을 바꾸려면 왼쪽 제목 아래의 ‘로그인’ 버튼은 로그인 성공 후 ‘로그아웃’으로 바뀝니다. ‘로그아웃’을 누르면 새 로그인창이 바로 열리므로 다른 부계정으로 로그인하세요. 로그아웃하면 자동 관리·반복 전송이 중지되고 저장한 로그인 정보가 삭제됩니다. BJ 설정과 신청곡은 유지됩니다. 로그인창을 취소해도 왼쪽에서 다시 열 수 있습니다.

실행할 때 WebView2가 필요하다고 나와요.

Microsoft 공식 WebView2 다운로드에서 Evergreen Runtime을 설치한 뒤 다시 실행하세요. .NET 실행 파일은 배포판에 포함되어 있습니다.

프로그램을 닫거나 방송이 끊기면요?

프로그램 종료 시 자동 반응도 멈춥니다. 처음에는 BJ 링크로 입장합니다. 방송이 종료됐으면 WATCH 목록을 BJ 아이디로 대조해 1초마다 확인하고, 방송 시작 시 다시 입장합니다. WATCH에 없으면 기존 전체 방송 목록을 30초마다 확인합니다. 접속 중에는 중복 입장하지 않으며 조회 오류 시 5초 후 재시도합니다. 강제퇴장 등은 상태 메시지를 확인하세요. 내장 방송창을 닫는 것은 숨기기이고, 메인 관리창을 닫으면 프로그램이 종료됩니다.

설정은 어디에 저장되나요? 업데이트는요?

이 PC의 사용자 폴더 %LOCALAPPDATA%\HaruPandaManager에 설정·신청곡·순위·로그인 정보가 저장됩니다. 자동 로그인을 선택하면 계정 정보는 Windows 사용자 기준으로 암호화됩니다. 이 폴더는 다른 사람에게 공유하지 마세요.

업데이트는 프로그램을 종료하고 새 ZIP을 모두 풀어 실행하세요. 기존 설정 폴더를 지우지 않으면 설정이 유지됩니다. Windows 자동 시작을 사용했다면 새 위치에서 옵션을 다시 저장하세요.

준비됐나요?

부계정 로그인 → BJ 추가 → 설정 저장 → 자동 관리 시작.
