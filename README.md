# 추억의 뽑기

등수별 상품명과 수량을 설정해 사용하는 웹 뽑기판입니다.

- 게임 목록: https://namharu.github.io/Game/
- 추억의 뽑기: https://namharu.github.io/Game/draw/
- 뽑기판 2: https://namharu.github.io/Game/lucky-board/
- 사다리: https://namharu.github.io/Game/ladder/

## 주요 기능

- 전체 뽑기 수 10~500개 설정
- 3등제부터 10등제까지 총 등수 선택
- 마지막 등수 전까지 상품명과 수량을 직접 설정
- 마지막 등수는 전체 수량에서 상위 등수 수량을 뺀 값으로 자동 계산
- 마지막 등수의 상품명도 `꽝`, `참가상` 등으로 자유롭게 변경
- 번호를 직접 선택하는 뽑기판
- 남은 상품과 뽑기 기록 표시
- 자동 저장 모드 사용 시 브라우저 `localStorage`에 진행 상태 저장
- PC 및 모바일 화면 지원

GitHub Pages에서는 저장소 루트에 이 파일들을 배치하고 `main` 브랜치의 루트를 배포 대상으로 설정하면 됩니다.
